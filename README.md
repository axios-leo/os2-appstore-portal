## 文件用途

| 路径 | 用途 |
|---|---|
| `modules/appstore-portal/` | 本人模块的原始源码与测试；待建模块只有说明 |
| `platform/` | 公共框架、总线接口、消息类型、日志、测试工具 |
| `contracts/` | 公共消息契约、本模块涉及的模型 Schema/示例 |
| `docs/` | 相关 RFC 和编码/安全规范原文 |
| `tools/` | 本包可用的契约生成检查及专属工具 |
| `CMakeLists.txt` | 本次新增的单模块根构建入口 |
| `SOURCE-MANIFEST.json` | 每个原仓库文件的路径、固定提交与 SHA-256 |
| `MANIFEST.sha256`、`verify_package.py` | 接收时的完整性校验 |
